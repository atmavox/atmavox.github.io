# ATMAVOX

Site oficial da **ATMAVOX**, marca da terapeuta Andreia Oliveira: autoconhecimento, presença e jornadas
individuais. Publicado em **https://atmavox.github.io**.

- **Hub** (`#/`): página da bio do Instagram, que leva a cada produto.
- **Jornada** (`#/jornada`): workbook interativo "Saindo do Estado Cinza — 21 Dias de Ativação da Chama
  Interna".

## Como rodar

Requer Node 24 LTS.

```bash
npm install
npm run dev         # http://localhost:5173
npm run check       # typecheck + lint + testes
npm run build       # build de produção em dist/
```
